Chapter 16 - Advanced Git
In this chapter I learned more advanced Git commands such as reverting, stashing, and resetting. Reverting can help undo changes while keeping a record of what happened. Stashing is useful when I needed to temporarily save changes without committing them. Ressetting can move the project back to a previous state. These commands are important because they give me more control when I make mistakes or needed to change my work.

Module7 helped me understand Git better and showed me different ways to manage changes in a project. I still need more practice with some of the advanced commands , but I am becoming more comfortable using Git and GitHub.
